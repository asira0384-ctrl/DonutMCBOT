# DonutBOT v1.0.0

DonutSMP向けの3アカウントBedrock BOT。検知・回収・パール装置の操作を、Railway上のWeb管理画面とDiscordから行います。

**起動手順は [START-HERE-JA.md](START-HERE-JA.md)。**

## 回収の動き

1. 検知BOTが死亡画面で待機。サーバーから受信した落下アイテムを、種類・個数・場所・ディメンションで判定します。
2. 指定条件に一致すると、回収BOTが `/home end` を送信します。
3. 設定座標への到着を確認し、必要なら落下地点まで歩きます。
4. 対象品が回収BOTのインベントリ内で実際に増えたことを確認します。
5. パールBOTがトラップドアを閉じます。
6. 回収BOTのサーバーからの位置更新と、設定した帰還地点への到着を確認します。
7. トラップドアを開き、回収BOTが同じ装置へパールを投げ直します。
8. 装置内で新しいパールが待機していることを確認して次の検知へ戻ります。

必要条件が揃わないとき、同時実行中、装置が範囲外、応答待ちがタイムアウトしたときは、理由を記録します。回収失敗時の帰還を試みる設定もあります。失敗した回収は自動で繰り返しません。

## 入っているもの

- 役割ごとのゲーマータグ・サーバー・接続バージョン設定。Bedrock版は初期状態でサーバーに合わせて自動選択。
- Microsoft公式のデバイスコード認証。保存された認証を再利用し、手動切断していなかったアカウントをアプリ起動後に再接続。
- 種類・個数・どれか／全部の画像付き回収フィルター。ダイヤ／ネザライト装備一式の追加。
- 体力、死亡状態、座標、Playerlist、36枠のインベントリ、装備・オフハンド、選択スロットのライブ表示。
- サーバーがホットバー上に表示したcombat残り秒数の読取り。Webでもホットバーの上に表示。
- 指定MCIDの座標へ歩く、継続追従、移動中の向きの同期。
- 拾った装備を自動装備。ダイヤやネザライトなどの性能が高い装備を優先。
- トーテムをオフハンド・メインハンドへ装備、最大7枠までホットバーへ配置。初期値5枠。トーテム発動を受信したら持ち替えと補充。
- 金リンゴ、エンチャ金リンゴ、ステーキを指定して食べる。サーバー側の個数変化で完了確認。
- BOTを指定して `/shop` などのコマンドを送信。Webでサーバーフォームにも回答可能。
- Webパスワード、HttpOnlyのセッションCookie、操作APIの送信元確認。
- 所有者限定のDiscord操作、重要イベントの **太字通知**、JSONレポートのダウンロード。
- 保存ログの容量制限・ローテーション、接続時の段階表示、再接続の待ち時間、サーバー転送への追従。

## サーバー側に依存する部分

**DonutSMP本番のアカウント・装置を使った試験は未実施です。** 通信スキーマ・認証状態遷移・連携手順は自動テストで確認しています。

- **死亡画面のまま落下アイテムを受信できるか** はサーバー次第です。死んでいるだけで全アイテムを見られるとは限りません。管理画面の「死亡中のアイテム受信」は、実際に受信するまで「未検証」と表示します。サーバーが送信を止めた場合は、この方法で検知できません。
- **他のプレイヤーの体力・遠距離座標・向き** は、サーバーが配信した情報だけ表示します。Playerlistにいても、範囲外の座標は分かりません。体力が届いていないプレイヤーは「未受信」です。
- `/home` のcombat制限・待ち時間、トラップドアの保護、装置の読み込み範囲、Java側のパール挙動はサーバー側の処理に従います。コマンドを送ったことと、コマンドが成功したことは区別します。
- 画像付きの条件設定は検知の開始条件です。回収完了は、対象品のうち1種類以上がインベントリで増えたことで判定します。条件に該当した品を全部回収できる保証はありません。
- パール待機の自動確認は、投擲後に装置内へ現れた新しいパールを観測します。パールの所有者情報をサーバーが送らない場合があるため、他の人が同時に投げない装置で使ってください。再投擲後に待機を自動確認できなければ、停止して人が確認する方式です。
- 自動装備・トーテム補充は、所持品とサーバーのインベントリ確認に従います。食事・投擲中は手の操作を順番に処理します。死亡や遅延を完全に防ぐことはできません。
- **ログイン情報の維持にはRailway Volumeが必要です。** Volumeを付ければトークンを残せますが、Microsoft側の失効・ログアウト・パスワード変更などで再認証が必要になる場合があります。

## Discord

`/donut panel`：操作パネル。`/donut logs channel:#チャンネル`：通知先を保存。

| コマンド | 動作 |
| --- | --- |
| `/donut status` | 全BOTの状態・体力・combat |
| `/donut auth bot:...` | Microsoft認証コードを本人だけに表示 |
| `/donut connect bot:...` | 保存したアカウントで接続 |
| `/donut disconnect bot:...` | 切断、自動再接続を止める |
| `/donut command bot:... text:/shop` | 指定BOTからコマンド送信 |
| `/donut home bot:...` | homeコマンド送信・到着確認 |
| `/donut respawn bot:...` | 手動リスポーン |
| `/donut eat bot:... item:...` | 食事 |
| `/donut follow bot:... player:MCID` | プレイヤーを追従 |
| `/donut follow bot:... player:off` | 追従OFF |
| `/donut inventory bot:...` | 所持品一覧 |
| `/donut players bot:...` | Playerlist・受信した体力 |
| `/donut watch enabled:true` | 自動回収を開始 |
| `/donut watch enabled:false` | 自動回収を停止 |
| `/donut pearl action:...` | パール投擲・待機手動確認・装置開閉 |
| `/donut cycle` | 回収サイクルを1回実行 |
| `/donut stop` | 全BOTの移動・自動回収を停止 |
| `/donut debug` | デバッグレポートを添付 |
| `/donut config` | 現在の設定JSONを添付 |
| `/donut config json:...` | Webと同じ設定をJSONで変更 |

設定JSON例：

```json
{"bots":{"collector":{"autoArmor":true,"autoTotem":true,"totemSlots":5}}}
```

```json
{"automation":{"requirements":[{"name":"elytra","count":1}],"match":"any"}}
```

`enabled` はJSON書換えでは開始しません。`/donut watch` またはWebの開始ボタンで装置の確認を通して開始します。

## デバッグコード

| コード | 意味 |
| --- | --- |
| `NOT_CONNECTED` | 対象BOTが接続していない |
| `DEAD` | 回収／パールBOTが死亡 |
| `DETECTOR_NOT_DEAD` | 検知BOTが死亡待機になっていない |
| `NO_ITEM_UPDATES` | 死亡中のアイテム受信が未検証 |
| `HOME_TIMEOUT` | homeの到着確認ができない |
| `PICKUP_TIMEOUT` | 対象品がバッグで増えていない |
| `NOT_ARMED` | パールの待機が未確認 |
| `TRAPDOOR_UNKNOWN` | ブロックの受信・距離・種類・開閉状態を確認できない |
| `TRAPDOOR_TIMEOUT` | 操作後の開閉状態を確認できない |
| `RECALL_TIMEOUT` | パール帰還の位置更新を確認できない |
| `REARM_TIMEOUT` | 再投擲・装置内の待機を確認できない |
| `PLAYER_NOT_VISIBLE` | 指定MCIDの座標が届いていない |
| `INVENTORY_REJECTED` | 装備・持ち替えのサーバー確認ができない |
| `FOOD_TIMEOUT` | 食事完了の個数変化がない |
| `CANCELLED` | 停止操作で中断 |

## 開発・依存

Node.js 24、`bedrock-protocol 3.60.1`、`minecraft-data 3.117.0`、`discord.js 14.27.0` を固定したlockfile付き。

```sh
npm ci --ignore-scripts
node scripts/prepare-raknet.js
npm run check
npm test
npm start
```

認証・チャンク・物理・インベントリの一部は、以前のAsira用BOTの実装を再利用しています。検知・回収の連携、管理画面、Discord管理、設定、診断はDonutBOT用です。不要な整地・攻撃機能は管理画面やコマンドに公開していません。

外部コードの出典・ライセンスは `vendor/bedrockflayer/`、`vendor/bedrock-palettes/` に同梱。アイテム画像はMojangのサンプルテクスチャに基づきます（`web/MINECRAFT-TEXTURES.txt`）。
